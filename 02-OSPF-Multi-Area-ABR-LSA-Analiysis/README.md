# Lab 02 — OSPF Multi-Area + ABR + LSA Analysis

## Objective

Configure a multi-area OSPF topology and verify inter-area routing and ABR behavior.

## Technologies

- OSPF
- Multi-Area OSPF
- Area 0
- Area 1
- ABR
- LSA Analysis
- GNS3
- Wireshark

## Lab Tasks

- Configure OSPF Area 0
- Configure an additional OSPF area
- Configure the ABR
- Establish OSPF neighbor relationships
- Verify inter-area routes
- Analyze OSPF LSAs
- Verify routing tables
- Perform packet analysis using Wireshark

## Verification

- OSPF neighbor relationships
- Routing table
- Inter-area routes
- OSPF database
- ABR information
- LSA analysis

## Evidence

The lab documentation is available in:

`OSPF.pdf`

The PDF contains the topology, OSPF configuration, path analysis, and Wireshark packet-analysis evidence.

## Key Learning

This lab demonstrates how OSPF uses Area 0, additional OSPF areas, and an ABR to provide inter-area routing.
