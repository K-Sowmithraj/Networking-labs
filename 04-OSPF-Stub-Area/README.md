# Lab 04 — OSPF Stub Area

## Objective

Configure an OSPF stub area and analyze how stub-area configuration affects external LSA propagation and routing information.

## Technologies

- OSPF
- OSPF Stub Area
- Area Design
- Type-3 LSA
- Type-4 LSA
- Type-5 LSA
- ABR
- GNS3
- Wireshark

## Lab Tasks

- Configure OSPF areas
- Configure an OSPF stub area
- Establish OSPF neighbor relationships
- Verify OSPF routes
- Analyze Type-3 LSAs
- Analyze Type-4 LSAs
- Analyze Type-5 LSAs
- Verify changes after stub-area configuration
- Analyze OSPF database information

## Verification

- OSPF neighbor relationships
- Routing table
- OSPF database
- Type-3 LSA
- Type-4 LSA
- Type-5 LSA
- Stub-area behavior
- Inter-area routing

## LSA Analysis

The lab analyzes how OSPF LSA information changes after configuring a stub area, including the handling of external routing information.

## Evidence

The lab documentation is available in:

`OSPF_BGP.pdf`

The PDF contains the OSPF topology, stub-area configuration, LSA analysis, and verification evidence.

## Key Learning

This lab demonstrates how an OSPF stub area changes the propagation of external routing information and reduces unnecessary external LSA information within the area.
