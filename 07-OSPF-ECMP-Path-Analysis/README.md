# Lab 07 — OSPF ECMP + Path Analysis

## Objective

Configure OSPF with multiple equal-cost paths and analyze how OSPF performs Equal-Cost Multi-Path (ECMP) routing and path selection.

## Technologies

- OSPF
- Equal-Cost Multi-Path(ECMP)
- OSPF Cost
- Equal-Cost Routes
- Traceroute
- ICMP
- Packet Capture
- Wireshark
- GNS3

## Lab Tasks

- Configure OSPF routing
- Configure OSPF interface costs
- Create multiple equal-cost paths
- Verify OSPF neighbor relationships
- Verify multiple routes to the destination
- Analyze OSPF path selection
- Perform traceroute testing
- Capture ICMP traffic using Wireshark
- Analyze the selected paths

## Verification

- OSPF neighbor relationships
- OSPF routing table
- Equal-cost routes
- OSPF cost
- Traceroute results
- ICMP packet capture
- Wireshark analysis
- ECMP path selection

## Path Analysis

The lab analyzes how OSPF selects paths when multiple routes have equal costs.

Traceroute and Wireshark packet captures are used to observe the forwarding paths and analyze ICMP traffic.

## Evidence

The ECMP and path-analysis evidence is available in the OSPF documentation:

[OSPF.pdf](../02-OSPF-Multi-Area-ABR-LSA-Analysis/OSPF.pdf)

## Key Learning

This lab demonstrates how OSPF uses equal-cost paths for ECMP and how traceroute and packet capture can be used to analyze network path selection.
