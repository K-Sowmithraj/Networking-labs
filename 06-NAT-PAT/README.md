# Lab 06 — NAT and PAT

## Objective

Configure and analyze different Network Address Translation (NAT) methods and verify address translation and connectivity.

## Technologies

- Static NAT
- Dynamic NAT
- PAT
- NAT Overload
- Inside/Outside Interfaces
- NAT Translation
- GNS3
- Wireshark

## Lab Tasks

- Configure NAT inside and outside interfaces
- Configure Static NAT
- Configure Dynamic NAT
- Configure PAT
- Configure NAT Overload
- Verify NAT translations
- Test network connectivity
- Analyze translated traffic using packet capture

## Verification

- NAT configuration
- NAT translation table
- Static NAT translation
- Dynamic NAT translation
- PAT translations
- NAT Overload behavior
- Connectivity testing
- Packet analysis

## NAT Analysis

The lab demonstrates how different NAT techniques translate private IP addresses into translated addresses for network communication.

The lab includes:

- Static NAT
- Dynamic NAT
- PAT/NAT Overload

## Evidence

The lab documentation is available in:

`NAT.pdf`

The PDF contains the NAT topology, Static NAT configuration, Dynamic NAT configuration, NAT Overload configuration, verification output, and packet-analysis evidence.

## Key Learning

This lab demonstrates how Static NAT, Dynamic NAT, and PAT/NAT Overload can be configured and verified in a Cisco networking environment.
