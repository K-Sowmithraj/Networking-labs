# Networking Labs

Hands-on Cisco networking labs built using GNS3, Cisco IOS, and Wireshark.

This repository documents practical networking labs covering routing,
network services, VPNs, NAT, packet analysis, and troubleshooting.

## Advanced Networking Labs

### 01. BGP + OSPF Redistribution + Type-5 LSA


- BGP configuration
- OSPF redistribution
- ASBR configuration
- Type-5 AS External LSA
- External route verification
- Wireshark analysis

### 02. OSPF Multi-Area + ABR + LSA Analysis

- OSPF Area 0
- Multiple OSPF areas
- ABR configuration
- Inter-area routing
- Type-3 LSA
- Type-4 LSA
- OSPF database analysis

### 03. OSPF Stub Area

- Stub area configuration
- ABR configuration
- Default route propagation
- LSA behavior

### 04. Site-to-Site IPsec VPN

- IKE / ISAKMP
- IPsec configuration
- Encryption and authentication
- Tunnel verification
- Packet capture analysis

### 05. NAT and PAT

- Static NAT
- Dynamic NAT
- PAT / NAT Overload
- Translation verification
- Packet analysis

### 06. OSPF ECMP and Path Analysis

- OSPF cost
- Equal-Cost Multi-Path routing
- Multiple paths
- Traceroute analysis
- Path verification
