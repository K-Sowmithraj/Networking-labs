# Networking Labs

Hands-on Cisco networking labs built using GNS3, Cisco IOS, Wireshark, and Solar-PuTTY.

This repository documents practical networking labs covering routing protocols, network services, redundancy, VPNs, NAT, packet analysis, troubleshooting, and network convergence.

## Repository Structure

Each lab contains documentation, topology information, configuration files, verification outputs, and packet-analysis evidence where applicable.

The repository is organized from advanced networking concepts to fundamentals so that the most technically advanced work is visible first.
