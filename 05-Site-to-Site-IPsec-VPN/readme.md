# Lab 05 — Site-to-Site IPsec VPN

## Objective

Configure a site-to-site IPsec VPN between two networks and verify secure communication between the sites.

## Technologies

- Site-to-Site VPN
- IPsec
- IKE/ISAKMP
- Encryption
- Authentication
- VPN Tunnel
- GNS3
- Wireshark

## Lab Tasks

- Configure the network topology
- Configure IP addressing
- Configure IKE/ISAKMP parameters
- Configure IPsec security parameters
- Configure VPN policies
- Establish the IPsec VPN tunnel
- Verify VPN tunnel status
- Test connectivity between the sites
- Capture and analyze VPN traffic using Wireshark

## Verification

- IPsec tunnel status
- IKE/ISAKMP status
- Connectivity between sites
- Encrypted VPN traffic
- Wireshark packet analysis
- ISAKMP packets
- ESP packets

## Packet Analysis

Wireshark is used to analyze the VPN traffic and verify the presence of:

- ISAKMP
- ESP
- Encrypted traffic

## Evidence

## Key Learning

This lab demonstrates how a site-to-site IPsec VPN can provide secure communication between two networks using authentication, encryption, IKE/ISAKMP, and ESP.
