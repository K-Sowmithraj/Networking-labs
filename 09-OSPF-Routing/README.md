# Lab 09 — OSPF Routing + Neighbor Adjacency Analysis

## Objective

Configure OSPF routing and analyze the OSPF neighbor-adjacency process using Wireshark packet captures.

## Technologies

- OSPF
- OSPF Neighbor Adjacency
- OSPF Hello Packets
- Database Description Packets
- Link-State Advertisements (LSAs)
- GNS3
- Wireshark

## Lab Tasks

- Configure OSPF routing
- Establish OSPF neighbor relationships
- Analyze OSPF Hello packets
- Analyze Database Description packets
- Analyze Link-State Advertisements
- Observe the OSPF neighbor-adjacency process
- Capture OSPF traffic using Wireshark

## Verification

- OSPF neighbor relationship
- OSPF Hello packets
- Database Description packets
- Link-State Advertisements
- OSPF packet exchange
- Wireshark packet analysis

## OSPF Neighbor Adjacency

The lab analyzes the process of establishing an OSPF neighbor relationship.

The packet exchange includes:

1. OSPF Hello packets
2. Database Description packets
3. Link-State Advertisements

Wireshark is used to capture and analyze the OSPF packets exchanged between routers.

This lab demonstrates how OSPF routers establish neighbor relationships and exchange link-state information using OSPF control packets.
